# 🎫 Ticket-Bot — Sistema de Tickets e Atendimento no Discord

Um bot completo para **suporte técnico**, **atendimento ao cliente** e **vendas automatizadas** dentro do Discord.

Ideal para servidores que oferecem serviços, produtos digitais ou precisam organizar atendimento com tickets privados.

---

## 🚀 Funcionalidades

✅ Painel interativo com botões  
✅ Sistema de tickets automático  
✅ Criação de canais privados por usuário  
✅ Categoria separada para:

- 🛒 Compras  
- 🛠️ Suporte

✅ Sistema de compra rápida via PIX  
✅ Registro automático de pedidos  
✅ Confirmação por envio de comprovante  
✅ Transcrição completa do ticket ao finalizar  
✅ Canal de logs para administração  
✅ Botões persistentes (não quebram ao reiniciar)

---

## 📌 Como funciona?

O bot cria um painel com botões no Discord:

- **Comprar** → abre um ticket na categoria de compras  
- **Suporte** → abre um ticket na categoria de suporte  

Cada ticket cria um canal privado onde somente:

- o usuário
- e a equipe autorizada

podem ver e responder.
